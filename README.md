About This Extension

A lightweight browser extension that allows you to quickly view the current price of a cryptocurrency. It also lets you switch between different price currencies or denominations, making it easy to check cryptocurrency prices in your preferred format.

Data Source: Cryptocurrency price data is obtained from the public CoinGecko API.
Refresh Interval: Prices are automatically refreshed every 1 minute (60 seconds).
Installation Guide

Follow the steps below to install the extension on a Chromium-based browser (e.g., Google Chrome).

Step 1: Download the Files
Download or clone this repository to your computer.
Extract the ZIP file if you downloaded it as a ZIP archive.
Make sure all extension files are placed inside a single folder.
Step 2: Open the Extensions Page
Open your browser.
Navigate to the Extensions page:
Google Chrome: chrome://extensions
Step 3: Enable Developer Mode
Locate the Developer mode toggle, usually in the top-right corner of the Extensions page.
Turn it on.
Step 4: Load the Extension
Click the Load unpacked button.
Select the folder containing the extension files.
Click Select Folder to install the extension.
Step 5: Verify Installation
The extension should now appear in your browser's Extensions list.
Pin the extension to your browser toolbar.

Installation complete! You can now start using the extension.

Updating the Extension

If you download a newer version:

Replace the old extension files with the new ones.
Open chrome://extensions.
Click the Reload button on the extension card.
